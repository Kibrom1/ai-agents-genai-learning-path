# Chapter 6: Agent Frameworks Survey & Standardization

*Phase 2 — Core GenAI Building Blocks*
## Learn
Compare a few agent frameworks/approaches (e.g. LangGraph, Anthropic's Agent SDK, a hand-rolled orchestration loop) and decide what you'll standardize on. Don't try to use all of them in production — pick one.

## Resources
- [Building Effective AI Agents — Anthropic](https://www.anthropic.com/engineering/building-effective-agents) — read this first, it's the conceptual foundation for the rest of this phase
- [Building agents with the Claude Agent SDK — Anthropic](https://anthropic.com/engineering/building-agents-with-the-claude-agent-sdk)
- [Workflows and agents — LangGraph Docs](https://docs.langchain.com/oss/python/langgraph/workflows-agents)

## Exercise
Rebuild the Chapter 5 agent in two different frameworks/approaches. Compare code complexity and debuggability.

## Deliverable
A one-paragraph decision record: chosen framework/approach and why.
