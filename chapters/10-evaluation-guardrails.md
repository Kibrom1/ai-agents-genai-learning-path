# Chapter 10: Evaluation, Guardrails & Prompt-Injection Defense

*Phase 3 — Agent Architecture Mastery*

Building eval sets for extraction accuracy, hallucination detection, and defending against prompt injection in any ingested documents/emails/external content.

## Exercise
Build a 15–20 item eval set for your extraction pipeline. Run it before and after a prompt change and track regressions.

## Deliverable
An eval harness (script + eval set) you can rerun on every prompt/model change going forward.
