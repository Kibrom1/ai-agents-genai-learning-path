# Chapter 5: Tool Use & Function Calling

*Phase 2 — Core GenAI Building Blocks*
## Learn
Designing tool schemas an LLM can call reliably, handling malformed tool calls, and parallel vs. sequential tool calls.

## Resources
- [Tool use with Claude — overview](https://platform.claude.com/docs/en/agents-and-tools/tool-use/overview)
- [Programmatic tool calling](https://platform.claude.com/docs/en/agents-and-tools/tool-use/programmatic-tool-calling)

## Exercise
Give an agent two tools — e.g. "look up a record by ID" and "check a record's status" — against a small mock dataset, and have it answer a question that requires chaining both calls.

## Deliverable
An agent that correctly chains both tool calls for a multi-step query.
